# decision-pane

English | [日本語](#日本語)

The landing page of [decision-pane](https://github.com/uehaj/uehaj-marketplace/tree/main/plugins/decision-pane), a Claude Code mod; served by GitHub Pages at https://uehaj.github.io/decision-pane/. The source of the mod lives in uehaj-marketplace. The page is in English and Japanese: it follows the browser's language, and the button at the top right switches it.
